# Dutch Dictionary Definition Expansion

This repository contains the code and data for the thesis 'Transformer-based Expansion of Dutch Dictionary Definitions' written by Robbe Meersman. It explores the automated expansion of Dutch dictionary definitions using Large Language Models.
<br><br>
**Grade: 16.5/20**

## Models

All models are fine-tuned using QLoRA and are available on Hugging Face:

* [aya-23-dutch-definition-expansion-qlora](https://huggingface.co/RobbedoesHF/aya-23-dutch-definition-expansion-qlora)
* [aya-101-dutch-definition-expansion-qlora](https://huggingface.co/RobbedoesHF/aya-101-dutch-definition-expansion-qlora)
* [geitje-ultra-dutch-definition-expansion-qlora](https://huggingface.co/RobbedoesHF/geitje-ultra-dutch-definition-expansion-qlora)
* [mt5-xl-dutch-definition-expansion-qlora](https://huggingface.co/RobbedoesHF/mt5-xl-dutch-definition-expansion-qlora)

## Dataset

The dataset used for fine-tuning the models was derived from the *Algemeen Nederlands Woordenboek (ANW)* and is available on Hugging Face:

* [dutch-definitions](https://huggingface.co/datasets/RobbedoesHF/dutch-definitions)
